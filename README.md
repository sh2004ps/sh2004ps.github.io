# Student Growth Portfolio

박성현의 학생 성장형 포트폴리오 정적 웹사이트입니다. 성장 과정, 학교생활, 군 복무 경험, 현재의 배움과 앞으로의 목표를 중심으로 구성했습니다.

## 주요 기능

- 반응형 레이아웃
- 다크모드 전환 및 저장
- CSS 애니메이션
- 버튼, 카드, 메뉴 hover 효과
- 무채색 기반의 투명한 글래스모피즘 스타일
- HTML, CSS, JavaScript 파일 분리
- 별도 빌드 없이 실행 가능한 정적 웹사이트

## 실행 방법

1. 이 폴더를 엽니다.
2. `index.html` 파일을 브라우저에서 실행합니다.

또는 VS Code를 사용한다면 Live Server 확장을 설치한 뒤 `index.html`에서 `Open with Live Server`를 선택하면 됩니다.

## 수정할 내용

제출 전에 아래 정보를 본인 정보로 바꾸세요.

- `index.html`의 이름, 학교 정보, 성장 연표, 소개 문장
- `index.html`의 Email, GitHub, Instagram 자리 표시자
- `style.css`의 디자인 세부값
